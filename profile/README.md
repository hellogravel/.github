# Hello Gravel

We sell rocks on the internet. Dump trucks, all 50 states.

Behind the simple product is a surprisingly deep technical stack. We build the infrastructure that makes buying bulk aggregate as easy as ordering anything else online.

## What we build

- **RockOS** — automates order flow from checkout to delivery
- **Chuck** — AI sales agent that closes deals end-to-end
- **Quarry** — Slack bot that runs operations
- **Dispatch** — unified knowledge base connecting 25+ systems
- Automated ad management, real-time pricing, and delivery logistics

We're building toward a fully agentic engineering pipeline — where AI teammates ship alongside humans.

## How we work

Everyone at Hello Gravel builds. Technical and non-technical teammates both open PRs and ship code.

We use AI tools as a real part of how we work, not as a crutch. Claude Code, Codex, agentic workflows — these aren't experiments, they're how we ship.

**Stack:** Python, JavaScript, React, Node.js, BigQuery, Cloudflare, Supabase, Playwright
